# zapret-py — простой DPI-обход для Windows

Маленькая базовая программа на Python, которая помогает обходить DPI‑блокировки
(YouTube, X/Twitter, Discord и т.п.) на одном Windows‑компьютере. Идеи
позаимствованы у проектов **bol-van/zapret** и **bol-van/zapret2**, а также у
популярного фронтенда **Flowseal/zapret-discord-youtube** — конкретно у конфига
`general (ALT11)`.

> **Важно:** программа НЕ запускает чужой `winws.exe` и НЕ требует устанавливать
> отдельный «zapret». Это собственная упрощённая реализация на Python+pydivert,
> которая повторяет ключевые идеи ALT11 (fake ClientHello + multisplit). Если
> позже захотите максимум скорости и совместимости — переходите на
> «настоящий» zapret. См. раздел «План улучшений».

---

## Как работает программа (простыми словами)

Когда вы открываете, скажем, **youtube.com**, ваш компьютер сразу после
установки TCP-соединения отправляет TLS-пакет «ClientHello», в котором открытым
текстом написано имя сайта (SNI). Российский DPI читает это имя и, если оно в
чёрном списке, режет соединение.

Программа делает две вещи одновременно:

1. **Fake ClientHello.** Перед настоящим запросом она отправляет несколько
   «фальшивых» TLS-пакетов с SNI = `www.google.com` и очень маленьким TTL
   (TTL=3). Эти пакеты быстро «умирают» в сети — до серверов Google они не
   доходят, но **успевают пройти DPI**. DPI видит «безобидный» google.com и
   дальше уже не блокирует поток.
2. **Multisplit.** Настоящий ClientHello она режет на два TCP-сегмента так,
   чтобы имя сайта попало на стык пакетов. DPI обычно проверяет каждый пакет
   по отдельности и не может склеить их обратно — а ваш браузер и сервер
   собирают всё корректно по TCP-уровню.

Совместный эффект: DPI «успокоен» (видит google.com), а реальное соединение
с YouTube/X идёт как обычно. Никаких серверов-посредников, никакого
шифрования сверху, никаких VPN.

Всё происходит на уровне сетевого драйвера через библиотеку **WinDivert**
(wrapper — `pydivert`). Это та же технология, что использует «настоящий»
zapret под Windows.

### Чем zapret2 отличается от zapret1 (коротко)

| | **zapret (1)** | **zapret2** |
|-|-|-|
| Когда появился | 2017 — первый прототип на shell + iptables (Linux), позднее `winws.exe` для Windows | 2024 — полностью переписанный движок |
| Реализация | C + bash, набор bat/sh-скриптов | C + **Lua** (логика стратегий вынесена в Lua-скрипты) |
| Стратегии | Hardcoded в коде, перечень фиксированный | Гибкая, описывается Lua-конфигом |
| Новые техники | fake, split, disorder | + multisplit, autottl, IP fragmentation, расширенный QUIC, лучше работает с WireGuard и Discord |
| Производительность | Хорошая | Заметно выше, особенно на медленном железе |
| Цель | Доказать, что метод работает | Промышленное решение |

Эта Python-программа — **третий, самый простой уровень**: она реализует только
самые важные техники (fake + multisplit) и работает «из коробки» без сборки.
Для максимума используйте оригинальный winws/winws2.

```

├── service.bat        ← запускайте это (двойной клик)
├── bypass.py          ← движок обхода (pydivert)

```

## Как запустить

1. Установите Python 3.10+ с https://www.python.org/downloads/
   (на установщике поставьте галочку **«Add Python to PATH»**).
2. Скачайте/распакуйте папку с проектом куда удобно (например, `C:\zapret-py`).
3. **Двойной клик по `service.bat`.**
   * Откроется консоль с запросом прав администратора (нужно нажать «Да»).
   * При первом запуске пункт меню «1. Запустить обход» сам поставит `pydivert`
     через pip — больше ничего ставить не нужно.
4. Выберите пункт меню цифрой и нажмите Enter.

### Меню service.bat

```
1. Запустить обход
2. Остановить обход
3. Добавить сайт/IP в список
4. Показать текущий список сайтов
5. Тест подключения (YouTube + X)
6. Статус сервиса
7. Установить зависимости (pydivert)
8. Открыть папку с логами
9. Выйти
```

Всё управление, проверки и тесты — через **service.bat**. Подробности при
этом всегда дублируются в `logs/log_YYYY-MM-DD.txt` — там вы найдёте
точные времена, ошибки и содержимое каждого шага, чтобы можно было разобрать
любую проблему задним числом.

### Как добавлять свои домены

Вариант 1 (через меню):

```
service.bat → пункт 3 → ввести домен (например, instagram.com) → Enter
```

Программа сама запишет домен в `domains.txt` (с проверкой дубликатов и
некорректных значений).

Вариант 2 (вручную): откройте `domains.txt` любым текстовым редактором и
добавьте строки. Один домен на строку. Поддоменные совпадения работают
автоматически (`youtube.com` в списке покрывает `www.youtube.com`,
`m.youtube.com` и т.п.).

После любых изменений в списке **перезапустите** обход
(меню → 2. Остановить → 1. Запустить).

### Как избежать конфликтов с VPN

DPI-обход работает на уровне сетевого драйвера и видит «сырые» пакеты.
Если у вас одновременно поднят VPN/прокси:

* трафик внутри VPN-туннеля **уже зашифрован**, и SNI извне не виден — обход
  ничего не сделает (он просто не увидит ClientHello к youtube.com);
* некоторые VPN-клиенты ставят свой WFP-фильтр, который конфликтует с
  WinDivert.

**Рекомендация:** перед запуском обхода **отключите VPN**. Если хотите
параллельно использовать VPN только для отдельных приложений — делайте это
через split-tunnel и вручную следите, чтобы трафик YouTube/X шёл напрямую,
не через VPN.

## Как протестировать, что обход реально работает

В меню есть пункт **5. Тест подключения** — он:

1. Делает DNS-запрос для `youtube.com` и `x.com`.
2. Открывает TCP-соединение на порт 443.
3. Проводит TLS-рукопожатие (это самый чувствительный к DPI этап).
4. Отправляет HEAD-запрос и измеряет:
   * время DNS,
   * время TCP-коннекта,
   * время TLS-рукопожатия,
   * время до первого байта ответа,
   * полное время.
5. Печатает в консоли сводку с вердиктом простыми словами:
   * **БЫСТРО** — total < 2 с,
   * **СРЕДНЕ** — 2–5 с,
   * **МЕДЛЕННО** — > 5 с,
   * **ОШИБКА** — соединение оборвалось.
6. Подробности (включая сам HTTP-status, ошибки, тайминги) пишет в
   `logs/log_*.txt`.

Запускайте тест **дважды**: при выключенном обходе и при включённом —
сравнивайте. Если разница огромная (например, при выключенном таймаут или
RST, а при включённом «БЫСТРО») — обход работает. Если оба раза «БЫСТРО» —
у вас и так нет блокировки на этом сайте.

## Как при желании собрать всё в один .exe

Если хочется отдать программу другу одним файлом (без установки Python):

```bash
pip install pyinstaller
pyinstaller --onefile --name zapret-py --add-data "domains.txt;." bypass.py
```

Результат: `dist/zapret-py.exe`. Запускать его придётся от администратора.
В `service.bat` тогда можно вместо `python bypass.py …` вызывать
`zapret-py.exe …` — остальная логика не меняется.

> **Антивирусы.** Любая программа, перехватывающая трафик через WinDivert,
> может вызвать ложное срабатывание SmartScreen/AV. Это нормальное явление
> для всех проектов класса zapret. При желании добавьте `.exe` и папку
> проекта в исключения антивируса.

## Логи

* Файлы: `logs/log_YYYY-MM-DD.txt` — один на каждый день.
* Каждая строка имеет формат:
  ```
  [2026-05-05 18:30:11.557] [INFO ] ...сообщение...
  ```
* Пишутся:
  * запуск/остановка сервиса,
  * каждый сработавший SNI и принятое решение,
  * статистика каждые 30 секунд (сколько пакетов прошло, сколько обработано,
    сколько ошибок),
  * полные тайминги тестов подключения,
  * стек-трейсы при сбоях.

Если что-то «упало» или сайт не открылся — приложите свежий `log_*.txt` к
багрепорту, по нему всегда можно восстановить, что произошло.

## Запуск unit-тестов (для разработчика)

```bash
pip install pytest
python -m pytest tests/ -v
```

Тесты не требуют Windows и не трогают сеть — они проверяют SNI-парсер,
сопоставление доменов, работу со списком и корректность фейкового
ClientHello.

## План улучшений на будущее

Эта первая версия — **намеренно простая и надёжная**. Она реализует только
два самых важных приёма (fake ClientHello + multisplit). Что планируется
дальше:

1. **Продвинутые техники DPI-desync:**
   * `fooling=ts/badseq/md5sig` — отдельные настройки фейков (как `--dpi-desync-fooling`);
   * `autottl` — автоматический подбор TTL по hop-count до сервера;
   * **IP fragmentation** для случаев, когда multisplit не помогает;
   * `disorder` — отправка сегментов в обратном порядке.
2. **Поддержка большего числа протоколов:**
   * **QUIC (UDP/443)** — fake QUIC initial с SNI google.com;
   * **WireGuard** — обход по UDP-handshake фингерпринту;
   * **Discord** — отдельные стратегии под голос (как `--filter-l7=discord,stun`).
3. **Переход на движок winws2 (C + Lua):** обёртка вокруг готовых бинарников
   bol-van/zapret2 даст максимальную производительность и совместимость;
   service.bat останется тем же — поменяется только бэкенд.
4. **Веб-интерфейс вместо консоли:** маленький локальный сервис на 127.0.0.1,
   управление через браузер, графики latency/успешности.
5. **Углублённая отладка и безопасность:**
   * белый/чёрный списки IP (`ipset-exclude`);
   * автоматическое определение «протекает ли DPI» по результатам тестера и
     подбор стратегии;
   * подпись `.exe` своим сертификатом, чтобы убрать SmartScreen-предупреждения.
